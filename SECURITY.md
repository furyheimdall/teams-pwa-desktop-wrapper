# Security Policy

## Supported versions

Security fixes are provided for the latest published `1.x` release.
Development snapshots and older releases may be replaced rather than patched.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use
[GitHub private vulnerability reporting](https://github.com/furyheimdall/teams-pwa-desktop-wrapper/security/advisories/new)
to share:

- the affected version and platform;
- reproduction steps or a proof of concept;
- the expected and observed behavior;
- the potential impact; and
- any suggested remediation.

If private vulnerability reporting is unavailable, contact the repository
owner through their GitHub profile without including exploit details in a
public message.

Reports are reviewed before public disclosure. Please allow time to reproduce,
fix, and publish an updated release before sharing technical details publicly.

## Scope

Reports about this Electron wrapper, its native desktop integrations, build
pipeline, or packaged artifacts are in scope.

Issues in the Microsoft Teams service itself should be reported to Microsoft
through its official security response process.
